## P2 — квитанция противоречит подтверждённой отправке Telegram

Место: `public/app.js:120`, общее сообщение при `data.channels.some(channel => channel.simulated)`.

Воспроизведение на искусственных данных:

1. Telegram успешно завершается в live-модели через MockTransport: `live_delivered`, simulated=0.
2. После перезапуска выполнить существующую операцию simulate для Sheets.
   Она переводит только оставшееся отключённое задание в тестовый режим; Telegram остаётся live_delivered.
3. Получить и отобразить квитанцию. Заголовок подтверждает создание сообщения Telegram,
   но ниже написано: «Проверка доставки выполнялась только на тестовом адаптере. Реальных отправок нет.»

Текст делает неверный общий вывод из тестового режима одного канала. Ошибка воспроизведена независимо;
реальных отправок для неё не выполнялось. Править точечно: обозначать тестовый канал по имени,
не отрицая другие live/unknown результаты. Не ослаблять независимость каналов и не запрещать
существующие локальные имитации ради обхода ошибки.

Для повторного среза: регрессия смешанных каналов (Telegram live_delivered/live_unknown + Sheets simulated),
проверка обычной тестовой квитанции, прежние тесты и обновлённый manifest. Визуальное направление не менять.
