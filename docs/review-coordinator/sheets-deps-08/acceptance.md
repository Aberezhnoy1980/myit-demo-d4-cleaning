## Рекомендация координатора о хосте

Предпочтительный кандидат — VAIO-LAB, отдельный изолированный контейнер Debian 12/Python 3.11.18.
Хост по исторической проверке — Debian 13; переустановка хоста не требуется этим предложением.
Наличие/пригодность Docker/Podman, ресурсы и доступ свежей проверкой не подтверждены.
До решения о создании среды — инвентаризация без изменений инфраструктурным исполнителем Perplexity
по business/portfolio/assignments/14-d4-linux-readiness.md. Хост остаётся предложением до этой сверки.

Для первого запуска использовать чистые временные данные и искусственные ключи.
Рабочая SQLite и реальные credentials на Linux не копируются. Нужны digest базового образа,
конкретные Node/procps/CA/bootstrap версии, пути/пользователь/лимиты/план сети и точная команда создания,
затем отдельное разрешение владельца. Автоматическое включение Docker/root-сокета/служб/портов не разрешено.
