# Описание демонстрационного кейса

07.11.2026. **«Диван в порядке» · «Химчистка диванов»** — самостоятельный вымышленный сервис.
Задача: помочь посетителю описать диван и приложить фото для последующего обсуждения работы.
Услуги не оказываются; исходный Weblancer 1270261 — рыночное свидетельство, не наш клиент.

Решение: оффер → подход без гарантий удаления пятен → форма с параметрами, тестовым контактом и фотографиями
→ серверная проверка → локальная транзакция SQLite → квитанция сохранения. Фото обрабатываются изолированно,
перекодируются в JPEG без исходных метаданных и хранятся закрыто. Есть предпросмотр/удаление фото,
ошибки, безопасный тестовый пример и защита от дублей неизменённого запроса.
Квитанция отличает локальное сохранение от независимых результатов каналов; смета и время выезда не назначаются.

Серверный этап/restore и офлайн-контракт B2 приняты координатором в проверенном объёме.
Проведён ровно один отдельно разрешённый тест Telegram: Bot API подтвердил сообщение,
владелец подтвердил получение и ручное удаление. Это свидетельство отдельного теста,
не постоянная/автоматическая доставка новых заявок. Повторять Telegram ради показа не разрешено.
Google Sheets/OAuth не подключены, настоящий SDK ещё требует отдельного решения о среде/установке и проверки.

Ограничения: только локальный показ с вымышленными контактами и безопасными тестовыми фото.
Текущий режим не готов к публичному приёму произвольных данных. Иллюстрация — лицензированный сток,
не выполненная работа и не «до/после». Нет публичной ссылки, реальных клиентов, продаж и маркетинговых результатов.

Показ: [docs/demo.md](demo.md). Сначала первый экран и переход к форме, затем ошибки/предпросмотр/удаление;
локальное сохранение и чтение квитанции показываются только на запущенном локальном backend, без внешней отправки.
Исторический Telegram-тест подтверждается протоколом, не повторяется в демонстрации.

ИИ участвовал в постановке, текстах, вёрстке, серверной реализации и авторских проверках.
Владелец утвердил дизайн/путь/тексты и новое имя; независимые проверки выполняет координатор.
Самопроверка исполнителя не присваивает статус «принято» всему кейсу.

Прежнее вымышленное имя «Тихий дом» использовалось до решения владельца 07.11.2026.
Исторические отчёты, снимки и идентификаторы с этим именем сохранены без переименования.
