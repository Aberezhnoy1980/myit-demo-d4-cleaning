2. В upload-box видна только одна область выбора. Настоящий файловый input прозрачен и покрывает область;
   он остаётся фокусируемым. `:focus-within` показывает контрастную рамку вокруг видимого элемента.

4. Переданы пять прямых серверных и две тестовые зависимости с точными версиями, назначением и командой установки.
