# Передача пересмотренного предложения зависимостей

07.11.2026 · `d4-tihiy-dom-sheets-deps-08`. Документальная ревизия для координатора, не новая кодовая реализация.
Основание — docs/review-coordinator/sheets-b2/acceptance.md и прямое поручение владельца.
Офлайн B2-07 принят в проверенном координатором объёме: 236 тестов и 104 исходных хэша.
Приёмка SDK/среды/live этим фактом не подменяется.

## Результат

Прежнее предложение со старым SDK/Python-RSA отозвано: библиотека архивирована и не сопровождается.
В исторические два proposed-файла добавлены датированные предупреждения, сами версии сохранены как история.
Новые выбор/ограничения — comparison.md. Основная рекомендация: отдельная согласованная Linux x86_64-среда
с текущими google-auth 2.62.1/cryptography 50.0.2 и готовыми wheel.

Поддержка Intel Mac в cryptography удалена с 49.0.0; source build 50.0.2 описан как неподдерживаемый эксперимент,
не гарантированное решение отсутствующего wheel. Наличие компилятора не возвращает upstream поддержку.
Выбор Linux не означает готовность/разрешение создать Linux/VM/Docker или перенести текущий проект/реестр.

## Выполненная проверка

- Читались публичные официальные docs, PyPI JSON и текстовые pyproject/Cargo файлы тега 50.0.2.
  Wheel/sdist/crates/образ не скачивались; pip resolver/install/dry-run/build, Rust/Cargo и Docker не запускались.
- Повторно сверены последние стабильные версии SDK и cryptography: 2.62.1 и 50.0.2.
- Для всех 33 Python-пакетов проверены requires_python, активные requirements/markers и точные версии
  отдельно для Linux CPython 3.11.18 и текущего Mac CPython 3.11.8.
- Linux-профиль: Debian 12/glibc 2.36/x86_64, cp311/abi3/py3 теги. Подходящие wheel — 33/33.
  Mac: текущие sys_tags, wheel — 32/33; отсутствует cryptography. Обязательная сборка других 32 не предполагается.
- Восемь ранее предложенных добавлений не устанавливались; вместо них новый Python-набор — прежние 24 + 9 = 33,
  без rsa/cachetools и без замены старых 24. Точный состав — runtime-33.txt/additions-9.txt, доказательства — metadata.json.
- Экспериментальный Mac builder: maturin 1.14.1, setuptools 84.2.1, cffi 2.1.1, pycparser 3.12.
  Проверены Mac wheel/активные зависимости и PEP 517 ограничения. Сборка/совместные импорты не выполнялись.
- MSRV Rust 1.83.0, исходный Cargo.lock: 40 записей с версиями/checksum в mac-build-metadata.json,
  SHA-256 официальных pyproject/Cargo файлов сохранены. Это исходный lock, не проверка резолюции target/features.
- Нативный профиль OpenSSL 3.5.9 LTS и требования CLT/SDK/clang/Rust/make/Perl описаны, не установлены/не проверены.
  Точные CLT/SDK/Rust pin, hashes native-дистрибутивов и base image digest ещё требуют отдельной фиксации.
- Отсутствие advisories у кандидатов PyPI не выдаётся за аудит. Наличие wheel не выдаётся за пригодность runtime
  или успешный импорт. Python-lock не выдаётся за полный lock OS/образа/native-компилятора.

Продуктовый код/тесты/инструменты и настройки не менялись; повторный runtime-прогон 236 тестов не выполнялся.
Результаты прежней независимой проверки не переизданы как новые. Вместо этого проверена побайтовая сохранность
всех ранее охваченных manifest файлов, кроме четырёх документов предложения. verification.json фиксирует сверку.

Сохранены реальные data/backups, 45 файлов ревьюера, исторический Mac-lock и 24 установленные версии.
Настоящие .env/ключи/Keychain не читались/не менялись, Google/Telegram не вызывались; среда не создавалась.
Business/общий хэндоф и другие демо не менялись. Редактура append в клиентской квитанции отложена до разрешённого кодового этапа.

и docs/server-dependencies.md. Добавлена эта папка сравнения/предложенных списков/метаданных/проверки.
