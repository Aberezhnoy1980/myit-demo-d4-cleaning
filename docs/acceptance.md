## Вес и метод

Файловые размеры в байтах, Python pathlib; JS gzip — gzip.compress(..., mtime=0).
`public/` содержит 6 файлов, всего **442 796 Б** (включая обе фотографии).
Одна мобильная подборка с фото 700 px — **122 268 Б**, одна desktop-подборка с 1400 px — **348 501 Б**.
JS исходный **5 879 Б**, gzip **2 190 Б** против бюджета 60 КБ gzip.
Preview gzip не включает: это оценка сжатия файла, не фактическая передача с сервера.
Файловые подборки меньше бюджета 1 МБ, но сетевой замер холодного мобильного старта не выполнен.
В журнале после изменения размеров есть запросы обеих фотографий; файловую подборку не выдаём за фактический сетевой вес.
Performance API недоступен в read-only окружении браузерного инструмента. Трафик, задержки и Web Vitals не измерены.

## Ограничения этапа

Не проверены настоящий zoom 200%, полная последовательность клавиатуры/скринридер,
реальный reduced motion, отключение JS/медиа, медленная сеть, размещение под префиксом.
CSS для reduced motion, noscript и alt присутствуют по чтению кода; это не результат испытания отказов.
Нет заявления соответствия WCAG по этому ограниченному протоколу.

Не проверены негативные фото, неверный контакт, длинный текст и повторный клик в браузере;
соответствующие клиентские ветви присутствуют, но их наличие не означает прохождение тестов.
Полный серверный перечень (повреждённые/огромные/подменённые файлы, транзакция, idempotency,
разрыв связи, перезапуск, сбой хранилища, каналы/таймаут/rate limit, очистка) относится к следующему срезу.
Сервер заявки отсутствует, его безопасность и приёмку нельзя подтвердить этим прототипом.

Инструмент selectOption дважды завершился таймаутом, нативный выбор с клавиатуры сработал.
Загрузка фото через file chooser инструмента заняла около 8 минут; измерением скорости сайта это не является.
Первые попытки снимков формы попали в движение плавной прокрутки; form-390/1440 пересняты после просмотра.
Preview завершён после проверки. Повторный запуск описан в README; файлы переданы для просмотра без дальнейшей записи.
